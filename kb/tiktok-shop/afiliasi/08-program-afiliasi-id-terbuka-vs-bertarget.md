# Program Afiliasi ID — syarat, akses, dan Terbuka vs Bertarget

## Ringkasan
Program Afiliasi = strategi marketing berbasis performa: kreator dapat komisi dari penjualan
lewat konten (video pendek) atau sesi LIVE mereka. Ini sumber ID (ShopTokopedia), jadi
**angka & alur di sini berlaku untuk TikTok Shop Indonesia** — beda dari materi TSP/Douyin.
Istilah "kreator", "afiliasi", "affiliator" dianggap sama (`M-D-MERGE-01`).

## Kapan ini dipakai
Waktu seller mau mulai kerja sama dengan kreator buat promosiin produk. Baca ini dulu sebelum
`tts-afiliasi-009` (kiat bikin produk dilirik kreator).

## Syarat gabung Program Afiliasi (ID)
- Rating toko **≥ 3,5 dari 5**
- Skor Kesehatan toko **≥ 12 dari 48**
- Produk sudah berhasil terunggah ke Seller Center ShopTokopedia

## Cara akses
**Seller Center > Promosi Afiliasi** (menu di bagian atas).

## Dua jenis kolaborasi
| | Kolaborasi Terbuka | Kolaborasi Bertarget |
|---|---|---|
| Gambaran | Produk tersedia dilihat & dipilih **semua kreator** di Marketplace Produk | Seller **mengundang kreator tertentu** |
| Pemilihan produk | Pilih produk untuk dipromosikan (komisi umum) | Pilih produk sesuai kreator yang diundang |
| Pemilihan kreator | Semua kreator (opsi "Setujui Kreator" bisa diaktifkan) | Kreator yang diundang via Username/User ID atau inbox |
| Komisi | Set komisi per produk | Komisi khusus per kreator/produk; bisa dilabeli "Komisi Lebih Tinggi" |

**Cara milih:** mau atur semua kreator berminat boleh promosiin → **Terbuka**. Mau kreator tertentu
aja → **Bertarget**.

**Struktur komisi per produk (Seller Center):** ada dua slot — **Standard** dan **Iklan Toko**
(mis. Standard 10,00% / Iklan Toko 5,00%). Produk otomatis masuk Kolaborasi Terbuka secara default;
komisi cuma dibayar kalau kreator berhasil menjual (bukan di muka). Referensi % per kategori di `tts-afiliasi-009`.

## Alur singkat
- **Terbuka:** Seller tambah produk ke Kolaborasi Terbuka → kreator cari di Marketplace Produk →
  tambah ke showcase/konten → penjualan masuk, kreator dapat komisi. Ada fitur "Penambahan Produk
  Otomatis" (set komisi umum, produk baru auto-masuk) & label "Direkomendasikan" (produk lagi diminati kreator).
- **Bertarget (4 langkah):** pilih kreator → pilih produk & atur komisi → siapkan sampel gratis
  (manual/otomatis) → kirim undangan ke inbox kreator.

## Batasan
Menu, syarat angka, dan nama fitur bisa berubah — **cek Seller Center terkini** sebelum instruksi
detail ke member (`K2-D-OUTDATED-03`). Angka referensi komisi ada di `tts-afiliasi-009`.
