# Mengelola Beberapa Gudang Saya dengan Fitur Multi-Gudang

17-03-2026

**Apa itu Multi-Gudang?**

Multi-Gudang adalah fitur di Seller Centre yang memungkinkan Anda menambah dan mengelola hingga 30 gudang untuk toko Anda. Anda dapat mengakses fitur ini melalui menu **Pengaturan** **Gudang** pada bagian **Pengaturan** **Toko** di Seller Centre.

  

Ikuti langkah berikut untuk mengakses fitur **Multi-Gudang**:

  
  

**⚠️ Catatan**

  - Fitur ini hanya tersedia untuk Penjual terpilih.
  - Jika Penjual Shopee Mall tidak dapat mengakses fitur Multi-Gudang, maka Anda dapat mempelajari lebih lanjut mengenai program[ Authorized Store](https://seller.shopee.co.id/edu/article/14435).

  

## **Keuntungan Menggunakan Fitur Multi-Gudang**

Berikut keuntungan yang bisa Anda dapatkan menggunakan fitur Multi-Gudang:

**Kriteria Penjual dan Cara Pendaftaran Multi-Gudang pada Halaman Gudang Saya**

Berikut adalah kriteria Penjual terpilih yang dapat mengaktifkan fitur Multi-Gudang:

  - Penjual yang memiliki toko cabang/gudang diberbagai daerah/kota.

  

Kemudian, daftarkan toko Anda dengan mendaftarkan gudang Anda pada Tim Shopee. Jika Anda menggunakan OpenAPI dan ingin daftar Multi-Gudang, mohon perhatikan langkah-langkah berikut:

  - Penjual dapat menghubungi Tim Shopee untuk mendaftar.
  - Penjual memberikan konfirmasi pada Tim Shopee bahwa setuju untuk melakukan integrasi ke API v2\* agar dapat mengaktivasi fitur Multi-Gudang pada halaman Gudang Saya.
  - Penjual Mengkonfirmasikan waktu integrasi API v2 pada Tim Shopee.
  - Shopee kemudian akan mengaktivasi Gudang Saya untuk Penjual yang berhasil melakukan penyesuaian API v2.

﻿﻿﻿﻿﻿﻿

\**Penjual dapat melakukan tes fungsional terlebih dahulu saat melakukan integrasi API v2 sebelum konfirmasi akhir kepada Tim Shopee untuk mengaktivasi fitur Multi-Gudang pada halaman Gudang Saya.*

***Menambahkan Beberapa Gudang dengan Fitur Multi-Gudang**

Ikuti langkah berikut untuk menambahkan beberapa gudang dengan fitur Multi-Gudang:

**⚠️ Catatan**

Anda disarankan untuk memilih lokasi sesuai titik karena pemilihan gudang untuk pemenuhan pesanan akan diperiksa melalui jarak.

  
  

Setiap gudang dapat diubah melalui halaman **Gudang Saya**. 

  

**⚠️ Catatan**

Saat ini, Anda tidak dapat menghapus gudang. Jika Anda sudah tidak memerlukan gudang tertentu, Anda dapat mengaktifkan Mode Toko Libur untuk gudang tersebut.

  - Apabila Anda belum mengaktifkan Gudang Pengembalian Pesanan atau Gudang Pengembalian Pesanan sedang dalam Mode Toko Libur, maka barang akan dikembalikan ke alamat gudang Pickup Pesanan yang sama saat pesanan tersebut dikirim.

**⚠️ Catatan**

  - Untuk membuat promosi produk, Penjual hanya dapat melihat total stok yang tersedia dari semua gudang (tidak termasuk gudang yang sedang dalam mode libur). 
  - Saat mengatur stok promosi, Penjual dapat mengatur stok promosi hingga total stok yang tersedia menggunakan sistem *floating* (promo dapat dipenuhi di gudang manapun selama stok masih tersedia).
  - Stok promosi tidak dapat dibedakan untuk setiap gudangnya.

  

**Mengaktifkan Mode Libur untuk Beberapa Gudang**

  

Mengaktifkan Mode Libur untuk gudang tertentu dapat mencegah adanya penerimaan pesanan baru untuk gudang tersebut. Anda dapat mengaktifkan Mode Libur jika Anda akan berlibur, atau gudang Anda tidak dapat memenuhi pesanan untuk sementara waktu karena keadaan yang tidak terduga.

  

Cukup tekan *toggle* **Mode Toko Libur** untuk mengaktifkan mode libur untuk gudang:

**⚠️ Catatan**

Perhatikan hal berikut saat Mode Toko Libur diaktifkan untuk salah satu gudang Anda:

  - Anda harus memenuhi semua pesanan yang sudah ada sebelumnya (sebelum Mode Toko Libur diaktifkan) pada gudang tersebut.
  - Jika ingin meliburkan seluruh gudang, silakan mengatur[ Fitur Mode Libur](https://seller.shopee.co.id/edu/courseDetail/39?lessonId=96) di halaman Pengaturan Toko.

  
**Mengatur Jasa Kirim untuk Multi-Gudang**

Anda tidak dapat mengaktifkan jasa kirim jika jasa kirim tidak dapat melayani min. 1 gudang yang terdaftar.

  

Jika Anda ingin menonaktifkan jasa kirim, sistem Shopee akan memvalidasi jasa kirim lainnya yang dapat melayani min. 1 gudang terdaftar. Jika tidak, Anda tidak dapat menonaktifkan jasa kirim terkait.

## **Tampilan Hasil Pencarian Barang**

Secara *default*, lokasi barang yang ditampilkan merupakan lokasi gudang yang memiliki stok tersedia dan memiliki jarak terdekat dengan alamat utama Pembeli.

  

Ketika menerapkan *filter* pencarian, sistem akan mempertimbangkan ketersedian stok barang. Apabila gudang tidak memiliki stok barang (0 stok), maka barang tersebut tidak akan ditampilkan.

  - Dikirim Dari

## **Tampilan halaman checkout**

Berikut adalah hal-hal yang menentukan alokasi gudang:

  - **\*\*Ketersediaan stok\*\***
  - **Prioritas gudang** - dihitung menggunakan jarak terdekat dari gudang Penjual ke alamat Pembeli.
  - **Alokasi gudang** - dilakukan selama proses checkout untuk menghitung estimasi ongkos kirim dan perkiraan barang tiba.

**Contoh**:

Alamat Pembeli berada di Jakarta dengan jarak ke masing-masing gudang tertera pada tabel di bawah. Maka, urutan prioritas gudang adalah Jakarta \> Bali \> Medan.

  - Jumlah barang  = 12

Pembeli akan diberi tahu melalui *pop-up* setelah memilih tombol **Checkout** untuk setiap pesanan yang harus dikirim secara terpisah, karena alokasi gudang ditentukan selama proses checkout.

  

Pembeli akan melihat 2 nomor pesanan berbeda untuk pesanan terpisah.

  

**Mengelola Pesanan untuk Pemilihan Gudang**

  

## **Pengiriman Pesanan Tunggal**

Tidak ada perubahan yang dilakukan pada halaman pengiriman pesanan tunggal. Anda dapat memenuhi pesanan seperti biasa. Setelah memilih **Atur Pengiriman**, Anda dapat memilih *drop off/pick up*.

## **Pengiriman Pesanan Secara Massal**

Tidak ada perubahan yang dilakukan pada halaman pengiriman pesanan massal. Anda dapat memenuhi pesanan seperti biasa tapi Anda dapat menyaring pesanan yang akan dikirim pada setiap gudang di halaman pengiriman massal.

  

## **Pengembalian Pesanan**

Anda dapat mengatur lokasi gudang tempat pengembalian barang dengan menambahkan Gudang Pengembalian Pesanan di Seller Centre.

Saat Anda mengaktifkan Gudang Pengembalian Pesanan, pengembalian pesanan akan dikembalikan ke alamat gudang tersebut. Apabila Anda tidak mengatur Gudang Pengembalian Pesanan atau Gudang Pengembalian Pesanan dalam Mode Toko Libur, maka pengembalian pesanan akan dikirim ke alamat gudang Pickup Pesanan yang sama saat pesanan tersebut dikirim.

  

**⚠️ Catatan**

  - Anda hanya dapat menambahkan maks. 1 gudang sebagai lokasi Gudang Pengembalian Pesanan.
  - Gudang Pengembalian Pesanan tidak dapat dihapus. Anda hanya dapat[ mengaktifkan Mode Toko Libur](https://seller.shopee.co.id/edu/article/14864) atau mengubahnya.

  

**Penyesuaian Open API Sebelum Mengaktifkan Multi-Gudang**

  

Anda yang menggunakan Open API perlu melakukan penyesuaian Open API v2 sebelum dapat mengaktifkan fitur **Multi-Gudang**. Perhatikan langkah berikut:

*\* Penjual dapat melakukan tes fungsional terlebih dahulu saat melakukan integrasi*

*API v2 sebelum konfirmasi akhir kepada ﻿﻿﻿﻿﻿tim Shopee untuk mengaktifkan fitur* 

***Multi-Gudang***

  

Perhatikan hal-hal berikut untuk penyesuaian Open API:

1.  API untuk fitur Multi-Gudang hanya tersedia bagi Penjual dengan API v2.
2.  Penjual yang menggunakan API harus menyesuaikan beberapa hal di bawah ini sebelum menggunakan fitur Multi-Gudang karena terdapat perbedaan struktur data.

  
**⚠️ Catatan**

Perubahan API terdapat pada **struktur stok**:

  - Untuk Penjual yang tidak menggunakan fitur Multi-Gudang, *payload* yang digunakan untuk stok adalah **normal\_stock**.
  - Untuk Penjual yang menggunakan fitur Multi-Gudang, *payload* yang digunakan untuk stok adalah **seller\_stock (location\_id, stock)**.
