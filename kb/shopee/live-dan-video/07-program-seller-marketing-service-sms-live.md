**Apa itu Seller Marketing Service (SMS) Live?**

Seller Marketing Service (SMS) Live adalah program yang membantu Penjual menjalankan sesi Livestream secara lebih optimal. Melalui program ini, Penjual akan mendapatkan bantuan mulai dari *Host* profesional, perlengkapan dan fasilitas Livestream, hingga strategi untuk meningkatkan performa Live toko Anda.



  

⚠️ **Catatan**

Program SMS Live saat ini hanya tersedia untuk Penjual yang memenuhi kriteria Shopee.

  

**Keuntungan bergabung program Seller Marketing Service (SMS) Live**

Dengan bergabung program SMS Live, Penjual dapat meningkatkan daya tarik Livestream dan menjangkau lebih banyak Pembeli melalui berbagai dukungan berikut:

**⚠️ Catatan**

Keuntungan bulan pertama berlaku khusus untuk Pengguna Baru (Penjual yang belum pernah bergabung program SMS Live).

  

**2. Persiapkan toko dan produk Anda**

Sebelum daftar pada program SMS Live, pastikan Anda:

  - [Membuat Sub Akun](https://seller.shopee.co.id/edu/article/6941/Tentang-dan-Akses-Yang-dimiliki-Sub-Akun) untuk *Host* Livestream dan[ atur peran sebagai KOL Livestreamer](https://seller.shopee.co.id/edu/article/8576)
  - Kirimkan sampel produk ke *Agency*/SSP
  - Toko Anda tidak memiliki poin penalti \>1 selama program berlangsung
  - Pastikan stok produk mencukupi
  - Berikan harga produk yang kompetitif

  
  

**3. Daftar program dan konfirmasi jadwal Livestream**

Jadwal Livestream akan ditentukan berdasarkan tanggal pendaftaran program.

|  |  |
| :-: | :-: |
| \*\*TANGGAL PENDAFTARAN\*\* | \*\*LIVESTREAM DIMULAI\*\* |
| Tanggal 11-26 | Tanggal 1 setiap bulan |
| Tanggal 27-10 | Tanggal 15 setiap bulan |

Penjual dapat mendaftar program ini dengan mengisi[ formulir Bergabung Program Seller Marketing Service (SMS) Live](https://shopee.co.id/program/form/5341).

  

**4. Komitmen durasi Livestream selama periode program**

Sesi Livestream berlangsung selama 30 hari sesuai jadwal yang telah ditentukan. Selama periode tersebut, sesi Livestream akan dijalankan oleh *Host* yang disediakan. Namun, Penjual harus berkomitmen untuk mengikuti program hingga periode berakhir.

  

**5. Pembayaran biaya layanan program**

Tagihan akan dikirimkan H+7 setelah periode Livestream selesai. Penjual dapat melakukan pembayaran melalui **Notifikasi** yang dikirimkan.

**6. Perpanjangan otomatis**

Program SMS Live akan berlanjut secara otomatis. Jika ingin berhenti dari program, Penjual dapat mengisi[ formulir Berhenti Program Seller Marketing Service (SMS) Live](https://shopee.co.id/program/form/5342) atau hubungi Tim Shopee sebelum tanggal 26 setiap bulannya.

  

**Syarat dan Ketentuan Seller Marketing Service (SMS) Live**

1\. Program SMS Live bersifat **opsional** dan hanya mencakup layanan Livestream.

  

2\. Dengan bergabung program ini, Penjual menyetujui bahwa:

  - Mengikuti program selama 30 hari penuh dan tidak dapat berhenti selama periode program berlangsung.
  - Dikenakan biaya layanan program sesuai paket yang dipilih (biaya layanan sudah termasuk PPN), dengan rincian berikut: 
  - Maks. periode Livestream: 30 hari/bulan
  - Min. total durasi Livestream: 60 jam/bulan atau setara 2 jam/hari
  - Bersedia mengirimkan sampel produk untuk keperluan Livestream, termasuk menanggung biaya ongkir dan pengembalian (jika terdapat[ pengembalian barang/dana](https://seller.shopee.co.id/edu/courseDetail/55?lessonId=3530)).

  

3\. **Khusus Pengguna Baru** akan mendapatkan keuntungan berikut pada bulan pertama:

  - ***Cashback*** **saldo Iklan Live s.d. 50%** dari total biaya layanan program (setelah PPN)
  - **Voucher Live XTRA** akan otomatis ditampilkan selama sesi Livestream berlangsung dengan **bebas biaya layanan**[ program Shopee Live XTRA](https://seller.shopee.co.id/edu/article/19969).

Jika tidak mengisi formulir[ Berhenti Program Shopee Live XTRA](https://shopee.co.id/program/form/5321), Penjual akan otomatis terdaftar dan dikenakan[ biaya layanan program Shopee Live XTRA](https://seller.shopee.co.id/edu/article/19968) pada bulan berikutnya atas pesanan berhasil dari sesi Livestream.

  - **Tambahan s.d. 5.000 Penonton Livestream** setiap harinya saat sesi Livestream berlangsung.

  

4\. Tagihan dikirimkan H+7 setelah periode Livestream selesai, dan wajib dibayarkan maks. 30 hari sejak tagihan dikirimkan melalui **Notifikasi**.

  

5\. Shopee berhak sewaktu-waktu mengubah keuntungan serta Syarat & Ketentuan yang berlaku, tanpa pemberitahuan terlebih dahulu kepada pihak mana pun. Pelajari lebih lanjut[ Persyaratan Layanan Program Seller Marketing Service](https://help.shopee.co.id/portal/4/article/143474).
