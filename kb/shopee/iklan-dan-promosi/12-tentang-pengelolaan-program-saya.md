# Tentang Pengelolaan Program Saya

## Ringkasan
Pengelolaan Program Saya adalah halaman untuk melihat dan memantau program opsional yang Anda ikuti, termasuk informasi dan rincian dari setiap program. Anda juga dapat menemukan rekomendasi program opsional lain yang sesuai untuk membantu mengembangkan bisnis Anda di Shopee.


10-06-2026

Pengelolaan Program Saya adalah halaman untuk melihat dan memantau program opsional yang Anda ikuti, termasuk informasi dan rincian dari setiap program. Anda juga dapat menemukan rekomendasi program opsional lain yang sesuai untuk membantu mengembangkan bisnis Anda di Shopee.

  

Pengelolaan Program Saya dapat Anda akses melalui Seller Centre.

  

Di halaman Pengelolaan Program Saya, Anda dapat melihat seluruh program telah diikuti beserta rincian informasinya pada **Program Opsional yang Sudah Tergabung** dan daftar program yang belum diikuti pada **Rekomendasi Program untuk Bergabung**.

  

**Program yang Sudah Tergabung**

Pada bagian ini Anda dapat melihat daftar serta rincian informasi dari masing-masing program opsional yang diikuti. Berikut adalah rincian informasi yang ditampilkan:

  - **Daftar Program**, menampilkan setiap program yang Anda ikuti beserta tanggal saat Anda bergabung.

  

  - **Keuntungan**, menampilkan keuntungan yang didapatkan jika Anda bergabung ke program.

  

  - **Biaya Layanan**, menampilkan informasi persentase biaya layanan program dan maks. biaya per kuantitas produknya.

  

  

  - **Status**, menampilkan status program yang berjalan seperti:

1\. Aktif: Anda telah berhasil tergabung pada program tersebut.

2\. Proses Keluar: Anda telah berhasil mengajukan pemberhentian program dan permintaan tersebut sedang diproses oleh Shopee.

3\. Sedang Berjalan: Anda telah berhasil mengajukan pendaftaran pada program dan permintaan tersebut sedang diproses oleh Shopee.

  

  - **Aksi**, pilih **Lihat Program** untuk melihat informasi dan rincian program yang telah Anda ikuti pada halaman **Rincian** program.

  

Pada halaman Rincian program, Anda dapat pilih **Keluar** untuk berhenti bergabung.

  

**Rekomendasi Program untuk Bergabung**

Pada bagian ini, Anda dapat melihat rekomendasi program opsional yang tersedia, keuntungan program, biaya layanan, serta status yang menunjukkan apakah toko Anda sudah memenuhi syarat untuk mengikuti program tersebut.

  - **Status**, akan menampilkan status "Memenuhi Syarat" yang menunjukkan bahwa Anda telah memenuhi syarat dan kriteria untuk mendaftar program.
  - **Aksi**, akan menampilkan aksi yang dapat Anda lakukan berdasarkan status program Anda.

<!-- end list -->

1.  Gabung Program: Jika Anda telah memenuhi syarat dan kriteria, Anda dapat klik Gabung Program untuk mendaftar.
2.  Pelajari Lebih Lanjut: Untuk melihat informasi lebih lanjut tentang rincian program.

  

**FAQ Umum**

**1. Apakah halaman ini tersedia untuk semua Penjual?**

Ya. Halaman Pengelolaan Program Saya sudah tersedia bagi semua Penjual.

Anda dapat mengakses halaman Pengelolaan Program Saya melalui Seller Centre, aplikasi Shopee \> Toko Saya, dan aplikasi Shopee Seller Centre. Pastikan Penjual sudah meng-*update* aplikasi ke versi terbaru.

  

**2. Apa manfaat utama dari halaman Pengelolaan Program Saya?**

Halaman Pengelolaan Program Saya dapat membantu Anda untuk:

  - Memantau dan mengelola program opsional yang diikuti
  - Melihat rekomendasi program opsional lainnya
  - Mengetahui status program, keuntungan program, dan biaya layanan secara lebih transparan

  

**3. Apakah biaya layanan yang ditampilkan sudah termasuk seluruh biaya yang dikenakan?**

Biaya layanan menunjukkan persentase biaya layanan yang berlaku pada program serta maksimum biaya yang dikenakan per kuantitas produk sesuai dengan ketentuan program.

  

Untuk ketentuan biaya lain selain biaya layanan, seperti biaya administrasi, akan mengikuti kebijakan Shopee yang berlaku.

  

**4. Apakah saya wajib mengikuti program yang direkomendasikan?**

Partisipasi dalam program yang direkomendasikan bersifat opsional. Anda dapat memilih untuk bergabung atau tidak sesuai dengan kebutuhan dan strategi bisnis masing-masing.
