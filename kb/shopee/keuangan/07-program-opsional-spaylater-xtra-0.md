# Program Opsional SPayLater XTRA 0%

## Ringkasan
**Apa itu Program Opsional SPayLater XTRA 0%?**


09-07-2026

**Apa itu Program Opsional SPayLater XTRA 0%?**

SPayLater XTRA 0% adalah program opsional yang memungkinkan Penjual untuk menawarkan **cicilan 0%** untuk Pembeli selama **3 atau 6 bulan** melalui metode pembayaran SPayLater. Program opsional ini dapat membuat produk Anda lebih terjangkau oleh Pembeli serta membantu meningkatkan penjualan.

**Keuntungan Mengikuti Program Opsional SPayLater XTRA 0%**

Dengan mengikuti program opsional SPayLater XTRA 0%, Penjual dapat memperoleh berbagai keuntungan, seperti:

  - Meningkatkan konversi pesanan toko Anda dengan adanya pembayaran yang lebih terjangkau untuk Pembeli.
  - Meningkatkan minat Pembeli terhadap produk Anda melalui metode pembayaran SPayLater dengan cicilan 0%.
  - Kemudahan dalam mengatur & mengontrol melalui Seller Centre dan aplikasi Shopee.
  - Biaya layanan yang terjangkau untuk Penjual.

  

Berdasarkan performa rata-rata Penjual yang mengikuti program opsional SPayLater XTRA 0%, program ini memberikan dampak positif terhadap peningkatan penjualan dan efisiensi biaya.

  - **\*\*Pertumbuhan\*\* \*\*\*Gross Merchandise Value\*\*\* \*\*(GMV) lebih tinggi\*\***

Penjual yang bergabung dengan program opsional SPayLater XTRA 0% mengalami kenaikan GMV hingga 8% dari bulan ke bulan.

  - **\*\*Transaksi SPayLater semakin meningkat\*\***

GMV dari Pembeli yang menggunakan SPayLater mengalami kenaikan hingga 30%. Hal ini mencerminkan Pembeli lebih tertarik berbelanja dengan opsi cicilan 0%.

  - **\*\*\*Return on Investment\*\*\* \*\*(ROI) positif untuk Penjual\*\***

Program ini mencatat ROI hingga 8x, di mana biaya yang dikeluarkan Penjual berpotensi memberikan hasil penjualan yang jauh lebih besar.

⚠️ **Catatan**

Pembeli dapat menikmati voucher diskon SPayLater senilai Rp300.000 khusus untuk metode pembayaran SPayLater XTRA 0%. Pembeli dapat melihat *tag* khusus di halaman produk:

  - *Tag* **CICILAN 0%**

  - *Tag* **Cicilan Murah 0%**

  - Halaman **Promo SPayLater**

**Siapakah yang Dapat Mengikuti Program Opsional SPayLater XTRA 0%?**

Program opsional SPayLater XTRA 0% hanya akan tersedia jika toko Anda telah memenuhi syarat dan ketentuan[ SPayLater](https://seller.shopee.co.id/edu/article/19954).

  

  
**Syarat dan Ketentuan untuk Mengikuti Program Opsional SPayLater XTRA 0%**

Sebelum bergabung dengan program, pastikan Anda memenuhi syarat dan ketentuan berikut:

  - Memiliki tingkat penjualan yang stabil.
  - Menunjukkan peningkatan performa toko secara bertahap.

**Biaya Layanan Program Opsional SPayLater XTRA 0%**

Biaya layanan adalah biaya yang dibebankan untuk Penjual pada setiap pesanan selesai yang menggunakan metode pembayaran SPayLater.

|  |  |  |  |  |
| :-: | :-: | :-: | :-: | :-: |
| \*\*TENOR\*\* | \*\*KETERANGAN\*\* | \*\*BUNGA YANG DIKENAKAN\*\*\*\*KE PEMBELI\*\* | \*\*BIAYA YANG DITANGGUNG\*\* \*\*\*PLATFORM\*\*\* | \*\*BIAYA LAYANAN PENJUAL\*\* |
|  3 bulan | Tanpa SPayLater XTRA 0% | 8,9% | 0% | 0% |
| Dengan SPayLater XTRA 0% | 0% | 6,4% | 2,5% |  |
| 6 bulan  | Tanpa SPayLater XTRA 0% | 17,8% | 0% | 0% |
| Dengan SPayLater XTRA 0% | 0% | 13,8% | 4% |  |

  

Biaya layanan dihitung berdasarkan **Total Penjualan** (termasuk biaya pengiriman yang dikurangi diskon (jika ada)) x **Biaya Layanan**. Berikut adalah ilustrasi biaya layanan SPayLater XTRA 0% dengan **tenor 6 bulan**:

  

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| Total penjualan dengan SPayLater tenor 6 bulan | \\= | Rp2.000.000 | a |
| Total diskon (Voucher Shopee, Voucher Toko, Voucher Bank) | \\= | Rp250.000 | b |
| \*\*Total Penjualan\*\* (a - b) | \\= | \*\*Rp1.750.000\*\* | c |
| Biaya layanan pesanan dengan SpayLater tenor 6 bulan | 4% | d |  |
| \*\*Total Biaya Layanan SPayLater XTRA 0%\*\* (c x d) | \\= | \*\*Rp70.000\*\* | e |
| \*\*Total Penjualan Bersih dengan Program SPayLater XTRA 0%\*\* (c - e) | \\= | \*\*Rp1.680.000\*\* |   |

  

Anda dapat melihat biaya layanan ini melalui halaman **Penghasilan Saya** di Seller Centre.

﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿

  

**⚠️ Catatan**

Jika fitur SPayLater Xtra 0% dinonaktifkan dan masih terdapat pesanan yang berjalan, Anda akan tetap dikenakan biaya layanan dari pesanan yang berjalan tersebut.

  

**Cara Bergabung & Berhenti Program Opsional SPayLater XTRA 0%**

**Cara Bergabung ke Program**

Anda dapat mengaktifkan program opsional SPayLater XTRA 0% melalui Seller Centre atau aplikasi Shopee dengan cara berikut:

﻿﻿﻿﻿﻿﻿﻿﻿

  
  

**Melalui Beranda Seller Centre**

  

Saat ini beberapa Penjual dapat langsung mengaktifkan program opsional SPayLater XTRA 0% melalui **Beranda**. Jika Anda melihat tampilan Beranda yang berbeda, Anda dapat mengaktifkan program opsional SPayLater XTRA 0% pada menu **Pengaturan Toko**.

**Melalui Seller Centre**

Pilih **Pengaturan Toko** pada menu **Toko \>** Pilih **Pembayaran \>** Geser *icon*  pada SPayLater Xtra 0% hingga berwarna hijau.

**Melalui aplikasi Shopee**

Pilih **Toko Saya \>** Pilih *icon* pengaturan **\>** Pilih **Pengaturan Pembayaran \>** Geser *icon*  pada SPayLater Xtra 0% hingga berwarna hijau.

**⚠️ Catatan**

Aktivasi program ini akan diterapkan ke toko Anda dalam waktu maks. 30 menit sejak *toggle* diaktifkan.

  

**Cara Berhenti dari Program**

Untuk keluar dari program opsional SPayLater XTRA 0%, Anda dapat menonaktifkan fitur dengan mematikan *toggle* SPayLater Xtra 0% melalui halaman **Pengaturan Pembayaran** di Seller Centre atau halaman **Pengaturan Keuangan** di aplikasi Shopee.

**Meninjau Performa Program Opsional SPayLater XTRA 0%**

Anda dapat melihat performa dari penggunaan SPayLater XTRA 0% melalui halaman[ Performa Toko](https://seller.shopee.co.id/datacenter/marketing/sspl).

  

Pada bagian **Kriteria Utama**, terdapat gambaran umum performa SPayLaterXTRA 0% seperti:

  - Penjualan
  - Pesanan
  - Biaya Layanan yang Dikenakan
  - Efektivitas Promo
