# Mengapa Toko Saya Dinonaktifkan atau Tidak Aktif?

## Ringkasan
Toko Anda mungkin telah dinonaktifkan atau menjadi tidak aktif karena tidak terdapat aktivitas Penjual apapun selama 90 hari kalender atau lebih.


13-03-2023

Toko Anda mungkin telah dinonaktifkan atau menjadi tidak aktif karena tidak terdapat aktivitas Penjual apapun selama 90 hari kalender atau lebih.

Anda harus melakukan setidaknya aktivitas berikut agar toko Anda dianggap aktif:

  - Mengakses Seller Centre
  - Mengakses halaman **Toko saya** di aplikasi Shopee
  - Mengakses toko Anda melalui API (*Application Programming Interface*)



  

ð **Definisi**

API (*Application Programming Interface*) merupakan perantara untuk dua perangkat lunak yang berbeda untuk dapat saling berkomunikasi satu sama lain. 

  

Jika Anda merasa tidak akan melakukan aktivitas penjualan dalam beberapa waktu, Anda dianjurkan untuk mengaktifkan[ Fitur Mode Libur](https://seller.shopee.co.id/edu/courseDetail/39?lessonId=96) untuk toko Anda sebagai gantinya.



  

⚠️ **Catatan**

  - Jika Anda tidak melakukan aktivitas Penjual selama 30, 60, atau 89 hari kalender, maka Anda akan menerima notifikasi untuk log in ke akun Penjual. Notifikasi ini akan dikirim melalui email (jika ada) dan/atau Notifikasi Toko (hanya dalam aplikasi Shopee).
  - Setelah 97 hari kalender tidak aktif, Anda tidak akan lagi melihat *tab* **Notifikasi Toko** di bawah halaman notifikasi Anda. Klik **Aktifkan Kembali** untuk mengaktifkan kembali toko Anda.
  - Mengakses *tab* **Notifikasi Toko** tanpa mengakses halaman **Toko saya** tidak dihitung sebagai aktivitas Penjual.

  

## **Pembatasan toko yang tidak aktif**

Karena toko yang tidak responsif akan memberikan pengalaman buruk kepada Pembeli Shopee, toko tidak aktif selama 90 hari kalender atau lebih akan menghadapi pembatasan ini:

  - Toko dan semua daftar produk akan disembunyikan dari hasil pencarian dan rekomendasi Shopee.
  - Akun Penjual tidak akan menerima Notifikasi Toko baik melalui Seller Centre atau aplikasi Shopee.

  

Penerapan pembatasan ini dapat membantu mengamankan kepercayaan Pembeli di Shopee, agar Pembeli dapat berinteraksi dengan Penjual yang aktif dan menarik.

  

## **Mengaktifkan kembali toko yang tidak aktif**

Jika toko Anda dinonaktifkan, Anda dapat mengaktifkan kembali toko Anda dengan melakukan hal berikut:

  - Mengakses Seller Centre
  - Mengakses halaman **Toko saya** di Aplikasi Shopee dan pilih **Aktifkan Kembali**
  - Mengakses toko Anda menggunakan API (*Application Programming Interface*)

  

**Pengaktifan kembali melalui Aplikasi Shopee**

Setelah diaktifkan kembali, semua batasan akan dicabut secara otomatis.



  

⚠️ **Catatan**

Menu **Toko Saya** akan tetap ditampilkan di halaman **Akun** di aplikasi Shopee Anda meskipun akun Penjual tidak aktif.
