# Mengakses Fitur Edit Secara Massal

## Ringkasan
3 cara edit produk massal di Seller Centre: Mass Upload (produk baru, pakai Template Dasar buat kategori apapun atau Template Kategori buat 1 kategori spesifik), Mass Update (edit produk existing pakai filter + template), dan Edit Atribut (khusus atribut, detail di `shp-produk-002`).

## Kapan ini dipakai
Dipakai buat arahin member yang mau upload/edit banyak produk sekaligus (bukan satu-satu manual). Kalau spesifik soal Edit Atribut massal, arahkan langsung ke `shp-produk-002`. Kalau soal upload produk baru satuan (bukan massal), arahkan ke `shp-produk-028`.

## Isi

**Mengakses Fitur Mass Upload**



**⚠️ Catatan**

Terdapat 2 *template* yang dapat Anda *download*:

  - **Template Dasar** dapat digunakan untuk kategori apapun (contoh: Pakaian Pria, Pakaian Wanita). Ketika menggunakan **Template Dasar**, Anda harus memilih dan memasukkan Kode Kategori produk Anda dari Daftar Kategori pada Seller Centre.
  - **Template Kategori** hanya dapat digunakan untuk satu kategori tertentu.

Pelajari lebih lanjut tentang menggunakan[ Template Kategori Mass Upload](https://seller.shopee.co.id/edu/article/20777).

  

**Mengakses Fitur Mass Update**

**⚠️ Catatan**

Anda dapat memilih **Template** yang Anda inginkan dan mengatur *filter* spesifik produk pada Mass Update.

Selanjutnya, buka *template* yang sudah di-*download* menggunakan Microsoft Excel. Pilih **Enable Editing** untuk mulai mengisi *template*.

  

**Mengakses Edit Atribut**

## Pertanyaan diagnosa

1. **Member mau upload produk BARU secara massal — pakai template yang mana?** Kalau produknya lintas kategori dalam 1 file → Template Dasar (perlu isi Kode Kategori manual). Kalau semua produk 1 kategori sama → Template Kategori (lebih simpel, kolom udah sesuai kategori itu).
2. **Member mau EDIT produk yang udah ada (bukan upload baru) secara massal?** Itu Mass Update, bukan Mass Upload — beda template & filter yang dipakai.
3. **Member cuma mau ubah atribut produk (bukan harga/stok/deskripsi)?** Arahkan ke fitur Edit Atribut / `shp-produk-002` — beda alur dari Mass Upload/Update biasa.
4. **Template Excel-nya gak bisa diisi/di-edit?** Pastikan udah pilih **Enable Editing** setelah buka file di Microsoft Excel — file *template* dari Shopee biasanya ke-protect secara default sampai di-enable.
